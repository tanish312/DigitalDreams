DIGITAL DREAMS WEBSITE

Files:
- index.html       Main website structure
- css/style.css    Custom styling, colors, effects and animations
- js/script.js     Tailwind configuration and website interactions

HOW TO USE:
1. Keep the index.html, css folder and js folder together.
2. Open index.html in a browser to preview the website.
3. Edit the HTML, CSS and JavaScript files separately as needed.

NOTE:
The website uses Tailwind CSS, Google Fonts and Font Awesome from online CDNs.
An internet connection is required for those external resources.
